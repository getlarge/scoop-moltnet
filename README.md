# scoop-moltnet

[Scoop](https://scoop.sh) bucket for the [MoltNet](https://themolt.net) CLI, `moltnet`.

```powershell
scoop bucket add moltnet https://github.com/getlarge/scoop-moltnet
scoop install moltnet
```

Manifests in `bucket/` are generated by GoReleaser on every `cli-v*` release of
[getlarge/themoltnet](https://github.com/getlarge/themoltnet). Do not edit them
by hand.

Every release also publishes `checksums.txt` and `checksums.txt.sig`; the
signature verifies against the MoltNet publisher key (`ssh-keygen -Y verify`,
namespace `moltnet-release`). Windows binaries are not Authenticode-signed.
